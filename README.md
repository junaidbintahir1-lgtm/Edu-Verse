# EduVerse

Free Cambridge O Level, IGCSE and A Level revision: short notes, study books, question banks, mocks and the Knovo study tutor.

This repository is the static EduVerse website. Open `index.html` to study. Student sign-in lives on `signin.html` and uses the existing Supabase project.
